## Topics to Review

Before moving further, make sure you can explain:

- What an iterable is.
- How a `for` loop processes items.
- Why `range(5)` stops at `4`.
- What `start`, `stop`, and `step` mean.
- The difference between `for` and `while`.
- How an accumulator works.
- How a counter works.
- How to maintain a running maximum/minimum.
- What `break` and `continue` do.
- What state means in an iterative algorithm.

---

## Practice Strategy

When practicing loops:

1. Predict the output before running the code.
2. Trace the loop one iteration at a time.
3. Write the algorithm before implementation.
4. Test boundary values.
5. Test negative values where applicable.
6. Check what happens when there is only one input.
7. Look for unnecessary nested loops or duplicated logic.
